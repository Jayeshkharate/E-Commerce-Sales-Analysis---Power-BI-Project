# E-Commerce-Sales-Analysis---Power-BI-Project
Analyzes sales, customers &amp; deliveries. Finds top products, tracks revenue trends &amp; improves logistics. Uses DAX/SQL for actionable insights. Helps boost profits with data-driven decisions.
Project Overview
This Power BI project provides a comprehensive analysis of an e-commerce company's sales performance, customer behavior, and logistics efficiency. The dashboard offers actionable insights to optimize revenue, improve customer experience, and streamline operations.

Key Features
Interactive Dashboards: Visualizations that highlight sales trends, customer demographics, and delivery performance

Revenue Analysis: Year-over-year and month-over-month revenue growth tracking

Customer Insights: Segmentation by value, gender, and purchasing patterns

Logistics Evaluation: Delivery time analysis across different shipping methods

Product Performance: Identification of top-selling and underperforming products

Return Analysis: Investigation into product return reasons and mitigation strategies

Technical Implementation
Data Sources: Processed and analyzed data from Orders and Customers tables

Data Cleaning: Handled null values in Location, ProductCategory, and Unit Price columns

DAX Functions: Utilized various DAX functions including:

RELATED, SUM, DISTINCTCOUNT

CALCULATE, AVERAGE, COUNTROWS

FILTER, SAMEPERIODLASTYEAR

Insights & Recommendations
Sales Optimization:

Target promotional campaigns in low-revenue months (June, September, November)

Implement discount strategies for underperforming high-value products

Customer Engagement:

Launch female-focused marketing initiatives to balance customer demographics

Develop tiered loyalty programs based on customer value

Logistics Improvement:

Expand Express delivery options to enhance customer satisfaction

Improve international shipping processes to reduce delays

Product Management:

Address quality issues to reduce returns (58% due to wrong/defective items)

Adjust pricing strategies for products with high prices but low sales
